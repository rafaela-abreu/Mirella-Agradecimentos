# Como adicionar fotos na galeria

1. Abra a pasta `public/uploads/` no repositório `Mirella-Agradecimentos`.
2. Arraste para essa pasta quantas fotos quiser (`.jpg`, `.jpeg`, `.png`, `.webp` ou `.gif`).
3. Faça o commit das alterações na branch `main`.
4. O GitHub Actions gera novamente a galeria e publica o Pages automaticamente.

Cada foto colocada nessa pasta aparece na galeria com o botão **↓ Salvar fotinha** logo abaixo. O convidado toca nesse botão para baixar a imagem no próprio celular ou computador.

Não é necessário criar uma conta ou acesso dentro do site para adicionar as fotos: basta ter acesso ao repositório GitHub para enviar os arquivos. O público só vê a página e pode salvar as fotos; não consegue enviar arquivos pelo site.
